Online Examination System

Project Description

Online Examination System is a Java-based project developed to conduct online examinations easily.

Features

1. Student Registration
2. Student Login
3. Multiple Choice Questions (MCQ)
4. Online Exam
5. Automatic Result Calculation
6. Result Display
7. Admin Module

Technology Used

- Programming Language: Java
- IDE: Visual Studio Code

Objective

The main objective of this project is to make the examination process easy, fast, and efficient.
